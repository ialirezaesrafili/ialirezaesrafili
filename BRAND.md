# Brand Guide

Visual identity used across this profile. Keep new sections and assets consistent with it.

## Mark

The **AE** monogram on a rounded square filled with the accent gradient. See [`assets/banner.svg`](./assets/banner.svg).

## Colour palette

| Role            | Hex       | Used for                                   |
| --------------- | --------- | ------------------------------------------ |
| Ink             | `#0B1020` | Banner background (start)                  |
| Surface         | `#0D1117` | Cards, badges, stat backgrounds            |
| Border          | `#30363D` | Card borders                               |
| Indigo (primary)| `#6366F1` | Primary accent, buttons, graph lines       |
| Indigo light    | `#818CF8` | Titles, typing text, badge logos           |
| Cyan (secondary)| `#22D3EE` | Icons, highlights, graph points            |
| Text            | `#C9D1D9` | Body text on dark surfaces                 |
| Muted           | `#8B949E` | Secondary text, dates                      |

**Accent gradient:** `#6366F1 → #22D3EE` (135°)

## Typography

- **Headings / UI:** Segoe UI, Inter, Helvetica, sans-serif
- **Code / accents:** JetBrains Mono, SFMono-Regular, Consolas, monospace

## Voice

Clear, confident and concise. Lead with outcomes, avoid filler, keep emoji to section headings only.
